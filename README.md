# Suite-Matematica
aplicacion que usa las Matematicas para el Diseño, y tener unos diseños ordenados y más armoniosos.

## Cómo pedir a una IA que implemente mejoras
Si quieres que una IA aplique mejoras en este repositorio, prueba con una solicitud clara que incluya los pasos deseados y los requisitos de entrega. Por ejemplo:

```
Necesito que migres la app a un flujo con bundler (Vite/Parcel) sin Babel en el navegador. 
Separar los componentes React y el CSS en archivos propios, conservar Tailwind o extraer estilos según convenga, y mejorar accesibilidad (atributos ARIA/tabIndex). 
Actualiza el README con instrucciones de instalación, ejecución y contribución. 
Tras los cambios, ejecuta las pruebas disponibles, describe el resultado y abre un PR con resumen y comprobaciones.
```

Recomendaciones para que la IA responda mejor:

- **Contexto**: menciona que la aplicación actualmente es un único HTML con React/Babel y estilos embebidos.
- **Alcance**: lista qué cambios son imprescindibles (bundler, modularización, estilos, accesibilidad, documentación) y cuáles son opcionales.
- **Entregables**: pide un commit, un mensaje de PR y la relación de pruebas ejecutadas.
- **Restricciones**: aclara si no debe cambiar dependencias, si quieres TypeScript o si debe evitar herramientas específicas.
